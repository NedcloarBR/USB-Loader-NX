# Manager themes

A theme changes the Manager's colors, sounds, fonts, images and layout. Copy its folder, or its `.zip`, to `usbloadernx/themes/` on the SD card and pick it in **Settings → Manager → Theme**, a list with a large preview; A applies the focused one right away. A theme in use is applied again as soon as its files change, so it can be edited over FTP or MTP while the Manager is open.

Every key, color and component is in [theme-spec.json](theme-spec.json), from which [theme.schema.json](theme.schema.json) (for editors: autocompletion and checks) and the tables below are generated by `tools/themes/generate_theme_docs.py`.

```text
usbloadernx/themes/<name>/
├── theme.json
├── thumb.png            optional: the theme picker's preview (or thumb.jpg, or the file in Images.Thumbnail; 320x180)
├── background.jpg       optional, named in theme.json (JPEG or PNG; 1920x1080 for a full screen; or an animated GIF/WebP)
├── font.ttf             optional, named in theme.json (TTF or OTF)
├── panel.png ...        optional: images in place of windows, cards, chips, buttons, the focus ring and icons
├── music.ogg            optional, named in theme.json (OGG, MP3 or WAV; loops)
└── sfx/                 optional: any of these replace the built-in sound
    ├── move.wav  select.wav  back.wav  whoosh.wav  open.wav
    ├── toggle_on.wav  toggle_off.wav  launch.wav  error.wav
    └── plug.wav  unplug.wav
```

## theme.json

```json
{
	"Format": { "Version": "2" },
	"Theme": { "Name": "Midnight", "Author": "NedcloarBR", "Version": "1.0" },
	"Colors": { "Primary": "#7C8CFF", "Ground": "#0F1424" },
	"Images": { "Background": "background.jpg", "BackgroundMode": "stretch" },
	"Sounds": { "Music": "music.ogg" },
	"Animations": { "Speed": "1.0", "Floating": "on", "Particles": "on", "FocusPulse": "1.6", "Easing": "out-cubic" },
	"Fonts": { "Regular": "font.ttf", "Scale": "1.0" },
	"Layout": { "Toolbar": { "Visible": "on" }, "Dock": { "Height": "60" } },
	"Carousel": { "Count": "5", "Arc": "0", "Scale": "1" },
	"Grid": { "Columns": "5", "Rows": "2" },
	"Views": { "Enabled": "carousel,grid,covers,boxes,shelves,list", "Default": "carousel" }
}
```

`Format.Version` is the version of this format the theme was made for (`"2"` since USB Loader NX 1.3.0, which added fonts, images, layout, views, easing and animated backgrounds; `"1"` for a theme without it). A Manager that only knows an older format still loads what it understands and marks the theme in the picker as made for a newer version. `Theme.Version` is the theme's own version, whatever its author likes.

A `<name>.zip` is unpacked into `<name>/` when the Manager starts, and again whenever the `.zip` is newer; `theme.json` can be at the archive's root or in one folder at its root. The `.zip` stays where it is.

Anything left out keeps the default, so a theme can change a single color. A `theme.json` that does not parse is ignored as a whole. File names are relative to the theme's folder and cannot leave it.

<!-- spec:keys -->
| Key | Values | What it does |
|---|---|---|
| `Theme.Name` | Text | Shown in the theme picker (the folder name otherwise) |
| `Theme.Author` | Text | Shown in the theme picker as "by …" |
| `Theme.Version` | Text | The theme's own version, whatever its author likes |
| `Format.Version` | `1`, `2` (default `1`) | The version of this format the theme was made for |
| `Images.Thumbnail` | A file of the theme: PNG, JPG | The preview in the theme picker (16:9, 320x180 is enough); without it `thumb.png`, `thumb.jpg`, then the background are tried, and with none of them the picker sketches the screen in the theme's colors |
| `Images.Background` | A file of the theme: JPG, PNG, GIF, WEBP | Drawn behind everything, over the `Ground` color. An animated GIF or WebP plays in a loop: up to 1280x720, 30 frames a second at most and 32 MB; WebP looks better and weighs less than GIF (256 colors) |
| `Images.BackgroundMode` | `stretch`, `tile` (default `stretch`) | How the background fills the screen |
| `Images.BackgroundDim` | `0` to `0.9` (default `0.4`) | How much of `Ground` covers the background image so text stays readable; over an image, the text areas also get a veil of `Ground` |
| `Images.Panel`, `.Card`, `.CardFocused`, `.Chip`, `.Button`, `.ButtonActive`, `.FocusRing` | A file of the theme: PNG | PNGs in place of windows, cards (and the focused one), the small chips, buttons (and the one A presses) and the focus ring; stretched in nine slices, so their corners keep their size |
| `Images.PanelBorder`, `.CardBorder`, `.CardFocusedBorder`, `.ChipBorder`, `.ButtonBorder`, `.ButtonActiveBorder`, `.FocusRingBorder` | `0` to `256` (default `16`) | How wide those corners are, in the image's px |
| `Images.Icon.Usb`, `.Clock`, `.Warning`, `.Chevron`, `.Star`, `.Package`, `.Grid` | A file of the theme: PNG | PNGs in place of the built-in icons |
| `Images.IconTint` | `on`, `off` (default `off`) | `on`: icons and the focus ring image take the color they are drawn in (draw them white); otherwise they keep their own |
| `Images.GameBackdrop` | `on`, `off` (default `on`) | The selected game's cover or icon, blurred, behind the home screen (the player can turn it off too); on by default unless the theme has its own `Images.Background` |
| `Fonts.Regular` | A file of the theme: TTF, OTF | A TTF or OTF (up to 16 MB) for all the text; letters it lacks (other scripts, button glyphs) come from the console's font |
| `Fonts.Scale` | `0.8` to `1.25` (default `1`) | The font's size against the console's |
| `Sounds.Music` | A file of the theme: OGG, MP3, WAV | Background music, under the sound effects; the player can turn it off in the settings |
| `Animations.Speed` | `0.25` to `4` (default `1`) | How fast transitions run (`1` as designed) |
| `Animations.Floating` | `on`, `off` (default `on`) | `off` keeps covers and icons still |
| `Animations.Particles` | `on`, `off` (default `on`) | `off` removes the drifting specks |
| `Animations.Easing` | `out-cubic`, `linear`, `out-quad`, `in-out-sine`, `out-back`, `out-elastic` (default `out-cubic`) | How transitions move (`out-back` goes a little past and settles, `out-elastic` springs) |
| `Animations.FocusPulse` | `0.5` to `6` (default `1.6`), or `off` | Seconds for the focus ring to go from `Focus` to `FocusAlt` and back; `off` keeps it still |
<!-- /spec:keys -->

## Layout

All sizes in px of a 1280x720 screen. A value out of its range is held to it; a carousel or grid that would not fit the screen goes back to the default (a grid first shrinks its covers to fit).

<!-- spec:layout -->
| Key | Values | What it does |
|---|---|---|
| `Layout.Edge` | `24` to `96` (default `48`) | The margin at the left and right |
| `Layout.Toolbar.Visible` | `on`, `off` (default `on`) | The bar at the top |
| `Layout.Toolbar.Y` | `0` to `40` (default `0`) | The bar's distance from the top |
| `Layout.Toolbar.Height` | `56` to `120` (default `80`) | The bar's height |
| `Layout.FreeSpace.Visible` | `on`, `off` (default `on`) | The drives' free space on the toolbar |
| `Layout.Dock.Visible` | `on`, `off` (default `on`) | The button hints at the bottom |
| `Layout.Dock.Height` | `44` to `90` (default `60`) | Their height |
| `Layout.Window.Width` | `760` to `1200` (default `960`) | The game window's width |
| `Layout.Window.Height` | `440` to `640` (default `516`) | The game window's height |
| `Carousel.Y` | `0` to `400` (default `104`) | Where the carousel's covers start |
| `Carousel.BigCover` | `160` to `360` (default `280`) | The selected cover |
| `Carousel.SmallCover` | `80` to `280` (default `184`) | The covers after it |
| `Carousel.Count` | `1` to `8` (default `5`) | Covers after the selected one |
| `Carousel.Gap` | `0` to `80` (default `24`) | Between covers |
| `Carousel.Arc` | `-120` to `200` (default `0`) | How much lower (or higher) the last cover sits, along a curve (`0`, a straight shelf) |
| `Carousel.Scale` | `0.6` to `1` (default `1`) | Each next cover this much the size of the one before |
| `Grid.Columns` | `3` to `8` (default `5`) | Columns of the grid (the Covers view has two more) |
| `Grid.Rows` | `1` to `4` (default `2`) | Rows of the grid |
| `Grid.Y` | `0` to `400` (default `104`) | Where the grid starts |
| `Grid.Cover` | `100` to `300` (default `200`) | Its covers |
| `Grid.GapX` | `0` to `80` (default `32`) | Between columns |
| `Grid.GapY` | `0` to `80` (default `24`) | Between rows |
| `Views.Enabled` | `carousel`, `grid`, `covers`, `boxes`, `shelves`, `list` | The views the theme offers, comma separated (`boxes` is the Cover Flow) |
| `Views.Default` | `carousel`, `grid`, `covers`, `boxes`, `shelves`, `list` (default `carousel`) | The view to start in when the player has not picked one |
<!-- /spec:layout -->

## Components

Each screen is made of named components, and a theme can move, resize, restyle or hide each one under `Layout.<Screen>` (`Home`, `Game`, `Drives`, `Settings`), and add components of its own. Positions are px of the 1280x720 screen; a component never leaves the screen, and a value that does not parse keeps the Manager's.

```json
"Layout": {
	"Home": {
		"info.name":      { "Anchor": "bottom", "Y": -150, "Width": 900, "FontSize": 40, "Align": "center" },
		"button.launch":  { "Visible": "off" },
		"clock":          { "Type": "clock", "Anchor": "top-right", "X": -48, "Y": 22, "Width": 120, "Height": 36, "FontSize": 30, "Align": "right" },
		"credits":        { "Type": "text", "Text": "{{game.developer}} · {{game.year}}", "Anchor": "bottom", "Y": -78, "Width": 900, "Align": "center", "Color": "#A3A6AD" }
	}
}
```

<!-- spec:properties -->
| Property | Values | What it does |
|---|---|---|
| `Anchor` | `top-left`, `top`, `top-right`, `left`, `center`, `right`, `bottom-left`, `bottom`, `bottom-right` (default `top-left`) | The screen's point the component's own same point sits at |
| `X` | `-1280` to `1280` (default `0`) | The offset from that point (without `Anchor`, from the screen's top left); without `X`, `Y` or `Anchor` the component stays where the Manager puts it |
| `Y` | `-720` to `720` (default `0`) | The same, down |
| `Width` | `1` to `1280` | Its width |
| `Height` | `1` to `720` | Its height |
| `FontSize` | `8` to `72` | For components with text |
| `Align` | `left`, `center`, `right` (default `left`) | The text within the component's width |
| `Visible` | `on`, `off` (default `on`) | `off` hides it |
| `Type` | `clock`, `battery`, `text`, `image`, `cover`, `box`, `icon` | Makes it a component of the theme's own (see the types) |
| `Text` | Text | For `text` |
| `Image` | A file of the theme: PNG, JPG | For `image` |
| `Color` | `#RRGGBB` or `#RRGGBBAA` | The text color of `clock`, `battery` and `text` (`Text` by default) |
<!-- /spec:properties -->

<!-- spec:components -->
**`Layout.Home`**

| Component | What it is |
|---|---|
| `logo`, `title` | The app's icon and name, on the toolbar |
| `chip.filter`, `chip.sort`, `chip.search`, `chip.drives` | The toolbar's chips (ZR, X, ZL and the drives' free space); each one's default place follows the ones to its right |
| `info.drive`, `info.name`, `info.chips`, `info.stats`, `info.alert` | Under the carousel: the drive, the name, the format/version/DLC/size chips, the play time and what needs attention |
| `button.launch`, `button.details` | The carousel's buttons |
| `counter`, `hints` | On the dock: "3 of 40" and the button hints (they end at the component's right edge) |

**`Layout.Game`**

| Component | What it is |
|---|---|
| `window` | The game window itself |
| `cover` | The cover (its smaller side is the size), with the format and drive under it |
| `title` | The name, with the favorite star after it |
| `details` | GameTDB's line and chips, the rows and what needs attention, from its top left |
| `button.launch`, `button.hide` | Launch, and Hide from / Show on HOME |

**`Layout.Drives`**

| Component | What it is |
|---|---|
| `window` | The USB drives window |
| `title`, `total` | Its title and the line with the free space and games of all drives |
| `cards` | Where the drives' cards start, and how wide they are |

**`Layout.Settings`**

| Component | What it is |
|---|---|
| `title` | "Settings" at the top of the sections |
| `sections` | The column of sections (its panel follows it) |
| `content` | The section's title, help and cards |
<!-- /spec:components -->

A component with a `Type` is the theme's own, under any name not listed above (`Home` only for now):

<!-- spec:types -->
| `Type` | What it shows |
|---|---|
| `clock` | The console's time (HH:MM) |
| `battery` | The battery's charge |
| `text` | `Text`, with the fields of the selected game |
| `image` | `Image`, a file of the theme, stretched to the component |
| `cover` | The selected game's GameTDB cover (else its icon), fitted inside the component |
| `box` | The selected game's GameTDB case (else its cover, else its icon), fitted inside the component |
| `icon` | The selected game's icon |

Fields of `text`: `{{game.name}}`, `{{game.version}}`, `{{game.size}}`, `{{game.drive}}`, `{{game.playtime}}`, `{{game.developer}}`, `{{game.publisher}}`, `{{game.year}}`, `{{game.genre}}`, `{{games.count}}`.
<!-- /spec:types -->

## Colors

<!-- spec:colors -->
| Color | Default | Used for |
|---|---|---|
| `Ground` | `#1E1F22` | Screen background, and the gap between a focused item and its ring |
| `Panel` | `#2B2D31` | Windows, cards, chips |
| `Raised` | `#35373C` | Selected cards and sections, cards inside windows |
| `Track` | `#404249` | Lines, borders, empty bars, switches turned off |
| `Text`, `TextSoft` | `#F2F3F5`, `#DBDEE1` | Text and button glyphs, and softer text and icons |
| `Muted`, `MutedSoft`, `Faint` | `#A3A6AD`, `#B5BAC1`, `#80848E` | Secondary text, from strongest to faintest |
| `Primary` | `#00C26F` | The app mark, the main buttons, switches turned on |
| `OnPrimary` | `#0E1A13` | Text and glyphs on `Primary` |
| `Focus`, `FocusAlt` | `#00C26F`, `#00B8C2` | The focus ring pulses between the two, with a glow |
| `Info` | `#00B8C2` | Links |
| `Star` | `#E3C800` | Favorites |
| `Warning`, `Pending`, `Error` | `#C2B200`, `#C27800`, `#C20E00` | With `Primary`, the drive usage bar: `Primary` up to 60%, then these up to 100% |
| `ErrorText` | `#FF6B5E` | Almost full drives, errors |
| `Alert`, `AlertSurface`, `AlertText` | `#E89A2E`, `#3A3020`, `#F3D3A0` | What needs attention: an update on another drive, fragmentation (line, box, box text) |
| `Overlay` | `#0C0C0ED1` | Over the screen behind a window (use `#RRGGBBAA`) |
<!-- /spec:colors -->

Sound effects are WAV files; short, quiet ones work best. [midnight](midnight/) is an example with every option; its background, preview and music are made by `tools/assets/generate_example_theme.py`.
